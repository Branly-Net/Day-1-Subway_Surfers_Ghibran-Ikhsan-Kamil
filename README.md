Repository adalah tempat penyimpanan atau wadah untuk mengelola file proyek, seperti source code, dokumen, gambar, dan file pendukung lainnya dalam satu tempat. Dalam dunia pemrograman, repository biasanya digunakan melalui platform seperti GitHub untuk menyimpan, mengatur, dan melacak perubahan kode program.

Tujuan/Kegunaan:
Repository ini dibuat sebagai tempat penyimpanan dan pengelolaan source code agar proyek lebih terstruktur, mudah dikembangkan, serta memudahkan proses kolaborasi dan pemantauan perubahan kode selama pengembangan aplikasi.

Pengertian Prompt: Instruksi atau masukan (berupa pertanyaan sederhana, kata kunci, instruksi rumit, hingga potongan kode) yang diberikan kepada model AI untuk memperoleh hasil tertentu.

Prompt Engineering: Seni dan teknik merancang instruksi agar AI memberikan jawaban yang tepat, relevan, dan layak digunakan.
Struktur Prompt yang Baik:
    Role: Menentukan peran AI.
    Task: Menyebutkan tugas utama atau tujuan (goal) yang ingin dicapai.
    Context: Memberikan latar belakang, batasan (constraints), dan syarat khusus.
    Format: Menentukan bentuk luaran (output) yang diharapkan.
Manfaat Prompt Engineering: Meningkatkan kinerja model AI, mengurangi bias dan respon yang ofensif, meningkatkan kontrol serta predictability, dan memberikan pengalaman pengguna yang lebih baik.

Managing Change with Git & GitHub
Pengertian & Perbedaan:
    Git: Sistem Version Control Terdistribusi (DVCS) lokal yang diciptakan oleh Linus Torvalds (2005) untuk melacak dan mengelola setiap           perubahan pada file.
    GitHub: Platform berbasis web untuk menyimpan repository Git secara daring (online) dan memfasilitasi kolaborasi.
Git Workflow:
    Working Directory: Direktori kerja tempat file aktif dikerjakan/dimodifikasi.
    Staging Area (Index): Area tempat menampung daftar perubahan file yang siap dimasukkan ke commit berikutnya.
    Git Directory (Repository): Tempat simpanan database metadata dan objek proyek secara utuh.

Poin-Poin Penting & Pengetahuan Baru

Struktur Prompt Berbasis Komponen:

Prompt yang spesifik dan berstruktur (Role, Task, Context, Format) menghasilkan keluaran AI yang jauh lebih presisi dibandingkan prompt        generik.

Perintah Dasar Git (Essential Commands):

git init: Inisialisasi repository baru.

git add . / git add -A: Memindahkan semua perubahan ke staging area.   

git commit -m 'pesan': Menyimpan perubahan yang ada di staging area ke dalam repository lokal.

git remote add <nama> <url>: Menghubungkan repository lokal ke remote repository (GitHub).

git push origin main: Mengunggah commit lokal ke repository remote.   

git pull origin main: Mengambil dan menggabungkan perubahan dari repository remote ke lokal.  

Autentikasi Aman Menggunakan SSH Key:

Pembuatan kunci menggunakan algoritma Ed25519 (ssh-keygen -t ed25519 -C "email@domain.com"), yang menawarkan keamanan dan performa tinggi      berdasarkan elliptic curve cryptography.
    
Konfigurasi SSH Agent dan pendaftaran Kunci Publik (id_ed25519.pub) pada pengaturan GitHub agar proses push/pull berjalan aman tanpa perlu     login terus-menerus.
